# Harris Hub — Personal Discovery Dashboard

Responsive personal dashboard for mobile and laptop. **No subscriptions, API keys, or build tools required.**

## Start immediately

Open `index.html` in a browser. All sections, curated search links, local preferences, checklists, and task tracking work without hosting. Public RSS feeds require the updater or deployment.

## Publish free to GitHub Pages (recommended)

1. Create a new GitHub repository (e.g. `harris-hub`). Upload the entire contents of this folder, including `.github/workflows/refresh.yml` and `update_feeds.py`.
2. In repository **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then save.
3. Visit the GitHub Pages URL shown there on laptop or iPhone. On iPhone, choose Safari **Share → Add to Home Screen** for app-like access.
4. In the repository **Actions** tab, run **Refresh public headlines** manually once using `workflow_dispatch`. It then runs daily around 11:17 UTC (scheduled GitHub Actions can be delayed).
5. If Actions cannot push, check repository **Settings → Actions → General → Workflow permissions**, and enable read/write permissions. Some repositories may also need Pages configured to use the branch.

## What's actually live?

- **Daily public RSS headline links:** Generated by the included Python updater, which queries Google News RSS. The feeds may fail temporarily or return noisy results; the updater preserves previous successful results. No scraping of reservation or sales sites.
- **Personal checklists, task tracker, sci-fi seen status, restaurant and comic watchlists:** Fully functional, stored **only in that browser's localStorage**. To transfer between phone and laptop, use Settings → Export preferences and Import preferences.
- **Reservation openings, comic deals, prices, codes, tickets, game schedules, and ski package prices:** **Not** monitored or verified automatically. These sections provide relevant direct searches, official links, and planning aids, not real-time alerts. Do not assume an opening, bargain, code, or deal exists without checking its source.
- **Google Scholar / podcast archive:** Settings can save URLs. Profile-based recommendation automation and past-guest analysis are not yet implemented.
- **No push notifications:** The static website and daily updater cannot send cancellation or deal alerts without additional service integration.

## Privacy

The website itself contains no analytics or account credentials. The watchlists and tasks are stored in each browser. Public GitHub Pages repositories expose the site's source code, so **do not commit private preferences or passwords to the repository**. The RSS updater only writes public headlines.

## Customize

- Edit the `defaults` object and section functions in `index.html` to change starter preferences and cards.
- Edit `QUERIES` in `update_feeds.py` to tune public headline feeds.
- To preview the feed updater locally, run `python update_feeds.py` (requires Internet). To preview website over HTTP, run `python -m http.server 8000` from this folder and open `http://localhost:8000`.

## Roadmap

Future upgrades could include authorized reservation-platform notifications, genuine sale-price comparison from permitted APIs, verified redeem codes, real-time sports/streaming data, Scholar-based literature matching, podcast guest candidate scoring, and optional cross-device synchronization. These require additional integrations and are **not claimed as present** in this version.
